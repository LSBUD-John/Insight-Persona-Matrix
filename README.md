# LSBUD Insight Persona Engine, Library and Recommendation Matrix

Static GitHub Pages prototype for the library-first Safe Digging Hub strategy.

## Files

- `index.html` - tabs for Engine, Library, Matrix and Rules.
- `data/personas.json` and `data/persona-matrix.csv` - persona recommendation source data.
- `data/library.json` and `data/library.csv` - free library catalogue.

## Deployment

Upload the files to a GitHub repo root and enable GitHub Pages from the main branch.

Suggested repo: `LSBUD-Insight-Persona-Matrix` or `LSBUD-Insight-Hub-Library`.
