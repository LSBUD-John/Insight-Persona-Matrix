# LSBUD Insight Persona & Recommendation Matrix

A static GitHub Pages prototype that turns the persona, purchasing authority and recommendation logic for **LSBUD Insight: The UK Safe Digging Hub** into an Excel-style interactive matrix.

## Contents

- `index.html` - self-contained web app with filters, matrix table and persona detail panel.
- `data/personas.json` - structured persona and recommendation data.
- `data/persona-matrix.csv` - Excel-friendly export of the same matrix.

## GitHub Pages deployment

1. Create a new GitHub repository, for example `LSBUD-Insight-Persona-Matrix`.
2. Upload `index.html`, `README.md` and the `data` folder.
3. Go to **Settings > Pages**.
4. Select **Deploy from branch** and publish from the `main` branch root.

Suggested URL after deployment:

```text
https://lsbud-john.github.io/LSBUD-Insight-Persona-Matrix/
```

## Product purpose

This matrix is intended to become the source of truth for persona-led recommendations in the future LSBUD Insight Hub.
