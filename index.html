Recommendation rules

1

Free library content first

Guidance, FAQs, Wiki entries, User Guides and Training should be recommended before gated transactions.

2

OneCall remains the anchor

Where the activity involves ground disturbance or utility risk, OneCall Utility Search remains the core site-specific utility search.

3

Site-specific services need site context

Reports, Large Site, Open Water, Environmental Constraints and search submissions should request location or geometry.

4

Purchasing power changes the call to action

Buyers receive quote, report and Pro options. Operational doers receive guidance, search prompts and manager escalation.

5

The matrix is the source of truth

Personas and Library items both remain structured data so they can drive the later LSBUD Insight Hub.
